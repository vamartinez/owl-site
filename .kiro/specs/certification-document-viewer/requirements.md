# Requirements Document

## Introduction

The Certification Document Viewer feature adds inline document preview capabilities to the admin portal's certification management table. Administrators can view uploaded certification documents (PDFs and images) directly within the application via a modal overlay, eliminating the need to download files or navigate away from the certifications list.

## Glossary

- **Admin_Portal**: The React-based web application used by administrators to manage workers and certifications
- **CertificationList**: The table component that displays worker certifications with columns for type, issuer, dates, status, and actions
- **Document_Viewer_Modal**: A modal dialog that renders an inline preview of a certification document
- **Identity_Service**: The backend Lambda service that handles worker and certification API endpoints
- **Signed_URL_Endpoint**: A GET API endpoint that generates a time-limited S3 signed URL for reading a stored document
- **Document_Key**: The S3 object key stored on a certification record, pointing to the uploaded file location
- **Signed_URL**: A time-limited pre-signed URL generated by S3 that grants temporary read access to a private object

## Requirements

### Requirement 1: View Button Visibility

**User Story:** As an administrator, I want to see a "View" button on certification rows that have an uploaded document, so that I can quickly identify which certifications have viewable documents.

#### Acceptance Criteria

1. WHEN a certification record has a non-empty document_key, THE CertificationList SHALL display a "View" button in the actions column for that row.
2. WHEN a certification record has no document_key or an empty document_key, THE CertificationList SHALL hide the "View" button for that row.
3. THE CertificationList SHALL render the "View" button alongside existing action buttons without replacing them.

### Requirement 2: Document Preview Modal

**User Story:** As an administrator, I want to click the "View" button to open an inline modal preview of the certification document, so that I can review documents without leaving the page.

#### Acceptance Criteria

1. WHEN the administrator clicks the "View" button, THE Document_Viewer_Modal SHALL open and display the certification document inline.
2. THE Document_Viewer_Modal SHALL include a visible close button that dismisses the modal.
3. WHEN the administrator clicks the close button, THE Document_Viewer_Modal SHALL close and return focus to the certifications table.
4. WHEN the administrator clicks the modal backdrop, THE Document_Viewer_Modal SHALL close.

### Requirement 3: PDF Document Rendering

**User Story:** As an administrator, I want PDF certification documents to render inline in the modal, so that I can read multi-page documents without downloading them.

#### Acceptance Criteria

1. WHEN the document content type is "application/pdf", THE Document_Viewer_Modal SHALL render the document using an iframe element.
2. THE Document_Viewer_Modal SHALL set the iframe source to the signed URL returned by the Signed_URL_Endpoint.

### Requirement 4: Image Document Rendering

**User Story:** As an administrator, I want image-based certification documents (JPEG, PNG) to display inline in the modal, so that I can view scanned certificates directly.

#### Acceptance Criteria

1. WHEN the document content type is "image/jpeg" or "image/png", THE Document_Viewer_Modal SHALL render the document using an img element.
2. THE Document_Viewer_Modal SHALL set the img src attribute to the signed URL returned by the Signed_URL_Endpoint.
3. THE Document_Viewer_Modal SHALL include an alt attribute on the img element describing the certification document.

### Requirement 5: Signed URL Generation Endpoint

**User Story:** As a frontend application, I want a backend endpoint that generates a read-only signed URL for a certification document, so that the browser can securely fetch the document from S3.

#### Acceptance Criteria

1. WHEN a GET request is received at /workers/{id}/certifications/{certId}/document-url, THE Identity_Service SHALL authenticate the request and verify the user has certifications:read permission.
2. WHEN the certification exists and has a document_key, THE Signed_URL_Endpoint SHALL return a JSON response containing a time-limited signed URL for reading the document.
3. THE Signed_URL_Endpoint SHALL generate signed URLs with an expiry duration matching the configured SIGNED_URL_EXPIRY_SECONDS value.
4. IF the certification does not exist, THEN THE Signed_URL_Endpoint SHALL return a 404 Not Found response.
5. IF the certification has no document_key, THEN THE Signed_URL_Endpoint SHALL return a 404 Not Found response with a message indicating no document is associated.
6. THE Signed_URL_Endpoint SHALL include the document content type in the response so the frontend can determine the rendering method.

### Requirement 6: Loading State

**User Story:** As an administrator, I want to see a loading indicator while the document URL is being fetched, so that I know the system is processing my request.

#### Acceptance Criteria

1. WHILE the signed URL is being fetched from the Signed_URL_Endpoint, THE Document_Viewer_Modal SHALL display a loading indicator.
2. WHEN the signed URL is successfully retrieved, THE Document_Viewer_Modal SHALL replace the loading indicator with the document preview.

### Requirement 7: Error Handling

**User Story:** As an administrator, I want to see a clear error message if the document cannot be loaded, so that I understand what went wrong and can take appropriate action.

#### Acceptance Criteria

1. IF the Signed_URL_Endpoint returns a 404 error, THEN THE Document_Viewer_Modal SHALL display a message indicating the document was not found.
2. IF the Signed_URL_Endpoint returns a network or server error, THEN THE Document_Viewer_Modal SHALL display a generic error message with an option to retry.
3. IF the document fails to load in the iframe or img element after the signed URL is obtained, THEN THE Document_Viewer_Modal SHALL display an error message indicating the document could not be rendered.
